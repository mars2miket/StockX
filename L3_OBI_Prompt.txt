Let ORDER_BOOK_MAP = Dictionary(Key: Order_ID, Value: [Price, Size, Side])
Let PRICE_LEVELS_BID = SortedDictionary(Descending)
Let PRICE_LEVELS_ASK = SortedDictionary(Ascending)
Let TRADE_DEQUE = SlidingWindowDeque(Duration = 1000ms)
Let SPOOF_REGISTRY = Dictionary(Key: Order_ID, Value: [Timestamp, Original_Size])
Let LAST_BROADCAST_TIME = 0

Define LAMBDA = 0.35
Define WEIGHTS = Vector([e^(-LAMBDA * i) for i in range(0, 10)])

[STAGE 2: DATABENTO ATOMIC MESSAGE EVENT LOOP]
---------------------------------------------------------------------------
For each incoming message (msg) from Databento L3 Feed:
    
    SWITCH msg.action:
        
        CASE 'A' (Add Order):
            ORDER_BOOK_MAP[msg.order_id] = [msg.price, msg.size, msg.side]
            Update_Price_Levels(msg.side, msg.price, delta = msg.size)
            
            # Track large orders for anti-spoofing
            IF msg.size > 500:
                SPOOF_REGISTRY[msg.order_id] = [msg.ts_event, msg.size]
        
        CASE 'M' (Modify Order Size):
            IF msg.order_id in ORDER_BOOK_MAP:
                old_price, old_size, side = ORDER_BOOK_MAP[msg.order_id]
                delta = msg.size - old_size
                ORDER_BOOK_MAP[msg.order_id][1] = msg.size
                Update_Price_Levels(side, old_price, delta = delta)

        CASE 'C' (Cancel Order) or 'F' (Full Fill Execution):
            IF msg.order_id in ORDER_BOOK_MAP:
                price, size, side = ORDER_BOOK_MAP[msg.order_id]
                
                # Check for Anti-Spoofing before deletion if Action is Cancel
                IF msg.action == 'C' and msg.order_id in SPOOF_REGISTRY:
                    inside_price = PRICE_LEVELS_ASK.keys()[0] if side == 'B' else PRICE_LEVELS_BID.keys()[0]
                    IF abs(price - inside_price) <= (2 * tick_size):
                        Flag_Spoof_Detected(msg.order_id)
                        # Drop volume from weighting matrix calculations
                        size = 0 
                
                Update_Price_Levels(side, price, delta = -size)
                
                # CRITICAL MEMORY MANAGEMENT FOR 16GB SYSTEM
                ORDER_BOOK_MAP.pop(msg.order_id, None)
                SPOOF_REGISTRY.pop(msg.order_id, None)

        CASE 'T' (Trade Execution Flag):
            # Track order flow aggression
            TRADE_DEQUE.append([msg.ts_event, msg.size, msg.side])
            
            # Iceberg Detection Logic
            visible_size_at_level = Get_Visible_Size_At_Price(msg.price)
            IF Cumulative_Trade_Volume_At_Level(msg.price) > (3 * visible_size_at_level):
                HIDDEN_ICEBERG_DELTA = Cumulative_Trade_Volume_At_Level(msg.price) - visible_size_at_level
                Inject_Iceberg_To_OBI(msg.side, msg.price, HIDDEN_ICEBERG_DELTA)

[STAGE 3: VECTORIZED METRICS & CALCULATIONS (NUMPY)]
---------------------------------------------------------------------------
Function Compute_Composite_Signal():
    # 1. Fetch Top 10 aggregated levels from memory dictionaries
    Bids_Vector = Get_Top_10_Sizes(PRICE_LEVELS_BID)
    Asks_Vector = Get_Top_10_Sizes(PRICE_LEVELS_ASK)
    
    # 2. Vectorized Exponential OBI Formula
    Weighted_Bids = NumPy.Sum(WEIGHTS * Bids_Vector)
    Weighted_Asks = NumPy.Sum(WEIGHTS * Asks_Vector)
    OBI_t = (Weighted_Bids - Weighted_Asks) / (Weighted_Bids + Weighted_Asks)
    
    # 3. Aggression Ratio Calculation
    Prune_Expired_Trades_From_Deque(Window = 1000ms)
    Agg_Buys = Sum(trade.size for trade in TRADE_DEQUE if trade.side == 'A')
    Agg_Sells = Sum(trade.size for trade in TRADE_DEQUE if trade.side == 'B')
    AR_t = Agg_Buys / Max(1, Agg_Sells)
    
    # 4. Generate Composite Confidence Score (0-100)
    Confidence = Normalize_To_Score(OBI_t, AR_t)
    
    Return Confidence, OBI_t, AR_t

[MATHEMATICAL FORMALIZATION & STATE ALGORITHM]

1. STATEFUL MEMORY STRUCTURE
Initialize a global dictionary: `order_book = {ticker: {"bids": {}, "asks": {}, "orders": {}}}`
Where `orders` maps `order_id -> (price, size, side)`.

2. LEVEL 3 ATOMIC EVENT PARSING
For each incoming Databento MBO message packet:
   IF action == 'A' (Add Order):
      Add order_id to `orders` tracking map.
      Increment the cumulative volume at that order's price level in the bids/asks book map.
   
   IF action == 'M' (Modify Order):
      Look up order_id to calculate the size differential (Delta).
      Update the cumulative volume at that specific price level by Delta.
      Update order_id size in `orders` tracking map.

   IF action == 'C' (Cancel) OR action == 'F' (Full Fill):
      Retrieve order_id from `orders` tracking map.
      
      # Anti-Spoofing Check
      IF action == 'C' AND original_size > 500 AND abs(order_price - NBBO) <= 2 ticks:
         IF cumulative_executed_volume_at_id < (0.05 * original_size):
            Flag order_id as [SPOOF]. Exclude its volume from the OBI calculation.

      Decrement cumulative volume at that order's price level.
      Delete order_id from `orders` memory map instantly using `del` to save RAM.

   IF action == 'T' (Trade/Execution):
      Identify the execution side. 
      IF side == 'A' -> Increment Aggressive Buy Volume queue.
      IF side == 'B' -> Increment Aggressive Sell Volume queue.
      
      # Iceberg Engine
      IF cumulative_trade_volume_at_price > (3 * visible_size_at_snapshot):
         Calculate hidden_delta = cumulative_trade_volume - visible_size
         Dyna-add hidden_delta to the active bid/ask volume matrix for OBI calculation.

3. DEPTH-WEIGHTED OBI VECTORIZATION
Every 50ms, extract the top 10 discrete price steps from the active `order_book`.
Calculate the exponential decay weight vector:
   w = np.exp(-0.35 * np.arange(10))

Compute the finalized Depth-Weighted OBI:
   Numerator = np.sum(w * Bids_1_to_10) - np.sum(w * Asks_1_to_10)
   Denominator = np.sum(w * (Bids_1_to_10 + Asks_1_to_10))
   OBI_t = Numerator / Denominator

4. COMPOSITE SIGNAL ENGINE
Calculate Aggression Ratio: AR = Rolling_Buy_Volume_1s / Rolling_Sell_Volume_1s
Calculate Composite Score: Score = (Normalized_OBI * 0.4) + (Order_Persistence * 0.3) + (AR * 0.3)
